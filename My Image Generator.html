✍️ Handwritten Notes Generator

Formatting rules:
• Main heading → black
• Lines ending with ":" → black
• Normal content → blue
• **word** → bold black word in normal text
• Java code → IDE-style dark card with syntax colors
• Arrow lines → blue
• Blank lines → spacing
• White 4:5 canvas
• Lines beginning with "class", "public", "private", "protected", "static", "int", "boolean", "String", etc. are treated as code.
• Paste tables from Excel, Word, or the web — they render as bordered tables.
